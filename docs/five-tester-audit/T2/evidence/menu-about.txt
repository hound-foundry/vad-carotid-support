ABOUT THIS PROJECT
About and privacy
A free, independent, open-source Hound Foundry community project for adults affected by vertebral or carotid artery dissection, families, carers and interested readers.
What this project is
This is an early development preview, not a charity, healthcare provider or medical service. It does not diagnose, interpret scans, recommend medication, estimate individual risk, clear activity or replace a clinician. Personal questions about diagnosis, tests and treatment belong with the person’s own care team.
Clinical and lived-experience review
All guides are original drafts with linked sources and recorded review fields. No clinician or patient/carer usability review has yet been recorded. The app must not publish these guides as approved patient information until qualified review is documented.
The user-suggested 2017 book is listed bibliographically as an external reading resource. Its chapters and stories are not reproduced or translated.
Privacy and open source
No account, analytics, advertising, sync service or backend is part of V1. Appointment sheets are stored on your device only when you choose Save. Web storage uses your browser profile’s local storage; native storage uses Expo SecureStore. Each has different device and backup behavior, so neither guarantees privacy. See the repository privacy documentation before storing sensitive notes.
The source code uses the project’s existing open-source licence, and authored guide content uses its existing content licence. The app is free to use; it has no donation, advertising or story-submission feature.

Languages
English is the only authored language in this preview. These languages are planned in stages, only after qualified human review of the interface and guides: Russian, Ukrainian, Lithuanian, Latvian, Estonian, Spanish, French, Japanese, Simplified Chinese, Traditional Chinese.
Use it like an app
On browsers that support installation, use the browser menu’s “Install” or “Add to home screen” action. The web version remains a static information tool: it does not create an account, add a server connection or change where saved sheets live.
How availability works
The basic English static web preview is available as general education and appointment preparation. It uses generic urgent-help wording and does not provide country-specific legal, medical or emergency claims. The project keeps a country watchlist before enabling local emergency details, additional languages, hosted data, paid features or native app-store distribution.
